# Estructura de datos

Este repositorio guarda los ejercicios de la materia, en el orden en que los fui trabajando. No es una librería: es el registro de lo que ya puedo construir en Python y de cómo lo fui entendiendo.

Lo dejo público para que se vea el avance demis aprendizajes. Cada carpeta corresponde a un tema. Dentro hay conceptos cortos y programas que se pueden ejecutar.

## Qué cubre

| Carpeta | Qué practiqué |
| --- | --- |
| `1.cadenas` | Texto: longitud, mayúsculas, reemplazo y búsqueda de caracteres. |
| `2.modular y busqueda` | Arreglos de una y dos dimensiones, filtrado y el primer manejo de excepciones. |
| `3.tipos de ordenamiento` | Selección, intercambio (burbuja) e inserción. También lectura y escritura de un archivo de estudiantes. |
| `4.Recursividad_prueba _estres.py` | Factorial, suma, conteo y búsqueda binaria escritos de forma recursiva. |
| `5.Tipos de archivos` | `with`, `read`, `write`, `seek` y `tell`. |
| `6.Componente practico,py` | Un menú que junta vectores, arreglos, matrices y un CSV de ventas. |
| `7.Ecepciones  y errores` | `try` / `except` / `else` / `finally`, y decisiones con `if` / `elif` / `else`. |
| `8.gestion de archivos` | Crear, leer y agregar líneas en un `.txt`. |
| `9. lista, pila y cola` | Lista, pila (último en entrar, primero en salir) y cola (primero en entrar, primero en salir). |
| `10 .Ejercicio` | Cola de atención: turnos, hora de llegada e historial de clientes atendidos. |
| `11. Arboles y Grafos` | Árbol binario de búsqueda (inserción y recorridos preorden, inorden y postorden) y conceptos de grafos. |
| `estructuras-esenciales` | Resumen de las estructuras base: concepto, para qué sirve y dos ejemplos de cada una. |

## Cómo leer el avance

Empecé por lo lineal: cadenas, listas y matrices. Después vinieron los algoritmos que recorren esos datos (ordenamiento y recursividad) y la forma de no romper el programa cuando falla una entrada o un archivo.

Lo más reciente aplica esas ideas a problemas concretos: una fila de atención con cola, y un árbol donde los menores quedan a la izquierda y los mayores a la derecha. El recorrido inorden de ese árbol devuelve los valores de menor a mayor.

Varios programas piden datos por consola (`input`). El de atención al cliente y el menú del componente práctico son de ese tipo. El árbol y la base esencial imprimen el resultado al correrlos.
